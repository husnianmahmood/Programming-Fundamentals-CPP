## 📖 Overview

This repository contains my C++ work developed during the study of
Programming Fundamentals.

The repository is organized into different sections to keep programming
exercises, assignments, and practical management-system projects structured
and easy to navigate.

The projects range from fundamental programming exercises involving arrays,
strings, functions, and mathematical computations to larger console-based
applications that simulate real-world billing, shopping, restaurant, utility,
and record-management systems.

The primary focus of this repository is to build a strong foundation in
C++ programming, logical problem-solving, structured programming, and
practical software development.

## 2. 💼 Management Systems

A collection of console-based C++ applications designed to simulate
real-world business, billing, customer-management, and transaction
workflows.

### Included Systems

### ⚡ LESCO Billing System

Simulates an electricity billing system with customer information,
billing calculations, taxes, duties, fees, and connection-cost estimation.

### 🛒 Grocery Mart Billing System

Simulates a grocery checkout system with product management, shopping
basket operations, billing, discounts, taxes, payment processing, and
loyalty points.

### 🛍️ Online Shopping System

Simulates an e-commerce platform with customer registration, product
management, shopping-cart operations, discounts, shipping costs, taxes,
and invoice generation.

### 🍽️ Restaurant Billing System

Simulates restaurant ordering and billing operations, including menu
selection, table orders, order tracking, tax calculations, and receipt
generation.

### 👥 Social Management System

A menu-driven application for managing social records, including user
registration, record storage, data manipulation, and record navigation.
