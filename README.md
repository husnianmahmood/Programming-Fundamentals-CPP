## 📖 Overview

This repository contains structured C++ implementations covering essential Programming Fundamentals concepts[cite: 1]. Developed during course lab sessions and assignments, each module focuses on core memory manipulation, low-level string processing, dynamic array traversal, and modular code design without relying on high-level external libraries[cite: 1].

---

## 🧠 Key Topics & Concepts

* **1D & 2D Array Processing:** Grid traversal, dynamic indexing, matrix addition/subtraction, and linear searching algorithms[cite: 1].
* **C-String Manipulations:** Custom implementation of string length computation, copying, reversing, vowel counting, and sorting without built-in `<string>` utilities[cite: 1].
* **Modular Functions & Overloading:** Reusable functional architecture, pass-by-array mechanisms, and function signature overloading[cite: 1].
* **Computational Logic & Math:** Exponentiation algorithms, GCD computation, leap year validation, temperature scaling, and sports data processing (strike rate, averages)[cite: 1].
